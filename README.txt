GENERIC FAMILY AUDITION COACH

This is a separate app. It does not modify Makenna's current site.

Features:
- 2 separate performer profiles
- separate Stage Stars and practice totals
- recording/playback stays on the device
- rotating greetings + original welcome chime
- configurable starter words and memory hints
- optional reward system per performer
- reward name, value/description, and points goal are configurable
- parents can change Stage Stars earned per recorded run

To share:
1. Create a NEW GitHub repository, e.g. family-audition-coach.
2. Upload every file in this folder to the repository root.
3. Enable GitHub Pages from main / root.
4. Share the Pages link with the family.
5. On first launch, they choose/manage the two performer names.
